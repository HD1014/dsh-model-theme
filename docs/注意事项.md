# 注意事项

## 安装前

1. **先备份** `%USERPROFILE%\.dsh\profiles\desktop\package.json`。
2. 本插件是本地插件，不是 DSH 官方组件；不要覆盖 DSH 安装目录。
3. 需要先装 `dsh-pet`，否则桌宠相关设置会显示但不会出现。
4. 桌宠包约 134 MB，解压和复制需要一点时间；不要在中途关闭 PowerShell。
5. **必须跑 `tools/patch-dsh-pet.ps1`**：`dsh-pet 0.4.7` 默认挂载所有 web 桌宠，光装主题插件不能彻底解决串台。脚本会先备份、后修改，并用 `node --check` 校验；`dsh-pet` 升级/重装后要重跑。

## 运行中

1. **只显示当前模型的一只桌宠**：主题插件广播 `dsh-pet-only`，`dsh-pet` 补丁按 id 过滤，未选中的宠卡不会挂载，所以不会再出现 A 模型念 B/C/D 台词的情况；没打补丁时这层过滤不生效。
2. **桌宠出界**：素材包里的水平偏移有的按宽屏多宠排布写成了 1200–1600px。插件在显示前会检测 rect，出界就拉回当前角落（默认右下 24/16），不会改你的原始 config。
3. **下拉面板**：原生 `<select>` 由插件绘制自定义白色面板，面板挂在 `body` 上，避免被设置弹窗的 `backdrop-filter` / `transform` 带偏。桌宠配置自带的下拉面板则用位置补偿修正。
4. **调色盘**：拖动时只改 CSS 变量，停手 260ms 后才写 localStorage；如果拖完立刻关设置，保存仍会在后台完成。
5. **主题主色**：会同时影响 HARNESS 角标、发送键、滑动开关；深底自动白字、浅底自动黑字。
6. **4 秒过场**：切换主题时旧桌宠会先卸载，目标桌宠在过场中段淡入；如果觉得太慢，可在设置里关掉「开关动画」。

## 兼容性

1. 主要测试环境：Windows 10/11、DSH 桌面版、`dsh-pet 0.4.7`。
2. DSH 升级可能改 class hash（如 `.AnXs9G_panel`、`GRgSLq_primary`），届时主题背景/玻璃面板/下拉定位可能需要补选择器。
3. 只对原生 `<select>` 做统一皮肤；第三方插件自绘的 combobox、日期选择器不受影响。
4. 语音音色下拉使用系统 / 插件提供的选项；本插件只改外观，不改语音引擎。
5. 自定义音效只接受 MP3，单个 ≤ 5 MB、时长 ≤ 5 秒。

## 开发

1. 改 `lib/client.template.js`，不要直接改 `lib/client.js`。
2. 构建后必须 `node --check lib/client.js`。
3. `client.js` 内嵌了七张主题背景，体积约 3.2 MB，属于正常。
4. 桌宠素材包不要提交到 Git 仓库：单文件超过 GitHub 100 MB 限制，请走 Release 资产。
5. 发布前跑一遍：`npm run check`，并确认 `assets/dsh-model-pets.zip` 的 371 个条目与 `pet` 目录一致。
